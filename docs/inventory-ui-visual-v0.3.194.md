# v0.3.194 — Inventory presentation system

Date: 2026-11-27. User approved the standalone custom-art inventory overhaul as the design foundation for future menus. Reference: four approved landscape images in the ongoing ChatGPT conversation (Equipment, Items, Materials, Quests); the source screenshots are not committed as flattened or unclickable UI.

## Scope and visual decisions
- Existing real Godot inventory data, 2014 D&D 5e starter gear, 15 equipment slots, player 3D character rigs, portrait mobile support, pause, save migration, combat, quest and item functionality remain intact. No models/skeletons/animations were created, changed or replaced.
- Target structure: left equipment slots framing the actual 3D character, right 4-column character/ability/combat/proficiency bar, right middle item grid and bottom selected item detail. Items/Materials/Quests use left category filters, central scrollable content and right information/actions. 1600x900 reference-relative desktop coordinates in code adapt to window size. No entirely static screenshot overlay.
- Distinct original artwork exported to nine-slice RGBA PNGs: `godot/ui_skin/panel(.png, _active.png)`, `slot(.png,_active.png)`, `button(.png,_active.png)`, `tab(.png,_active.png)`, `header.png`. All source 256x256 textures, full quality, no lossy compression/downscale. `portrait_backdrop.png` is an opaque 380x620 charcoal/stone texture for the 3D character stage. Editable source generator: `blender/ui_skin/polish_v194_art.py`. Godot loads a purpose-designed texture per control instead of applying one ornate frame to every tiny slot.
- The former world-translucent inventory panels were replaced with dark opaque leather; a dark backdrop covers the world, and the gameplay HUD becomes invisible when inventory opens and returns on close. The actual game tree remains paused; the overlay remains PROCESS_MODE_ALWAYS. All four tabs remain responsive during a pause.
- Character preview preserves existing selected player GLB with adjustable turn controls and existing armor visual switching. Portrait surface now has stone/haze art, not a plain black void, with more useful camera framing. Character statistics show *real* known values; missing scores/proficiencies remain explicitly unrecorded rather than invented to match the reference screenshot.
- Item grids are fixed so atlas icons fit inside slots without spilling into neighboring rows. Materials still shows zero when none collected, Quests only actual Goblin Menace until more quests are implemented. Item descriptions and rules snippets for a few known starter items are visual-only and do not invent consumable/drop gameplay. Unsupported Drop/Use remains disabled, and Compare remains preliminary.

## Known visual gaps and next work
- Visual hierarchy, opacity, spacing, icon containment and ornament repetition are substantially improved versus v0.3.193, but this is **not pixel-perfect reproduction** of the four approved high-detail fantasy references. The custom drawn bronze corners/frames are less detailed than image references, and existing game art still lacks many target-quality icons and full item database detail.
- Stats placeholders use live available data; full six ability scores and proficiency data need an actual character system before they can be populated legitimately.
- Material crafting contents and other quest rows need game-content additions, not visual fabrication.
- Portrait mobile layout uses the new generic frame skins but keeps the existing portrait arrangement; desktop landscape is the visual-focus target and needs device comparison.
- These nine-slice assets are intended to become reusable across menus; they are not yet applied to shop, dialogue, character creator, settings or other screens.
