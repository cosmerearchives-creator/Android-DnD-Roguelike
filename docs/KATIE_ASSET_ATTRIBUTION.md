# Katie model attribution

The Katie face, eyes, eyelashes, eyebrows and scalp used by **Forests of Hell** were derived from the 3D model **Katie (hair and skin render)**, Blend Swap asset #69006, by **Rick Savage**.

Source: http://www.blendswap.com/blends/view/69006
License: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)

The developer supplied `Katie - Version 2.01.zip` / Google Drive copy of the asset, including its license and artist credit. This project modifies the original artwork for mobile gameplay: scaled-down texture maps, rebuilt Godot-friendly materials, mesh-based hair, and replacement full-body geometry and animations from the existing Forests of Hell procedural Petite Scout character. The result is a derivative work and is not the original artist's complete playable rig.

The original high-resolution ZIP and Blender file are **not** included in this repository. The game includes optimized GLB derivatives. Retain this credit when distributing those derivatives and the game.
