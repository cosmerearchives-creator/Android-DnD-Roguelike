# World position save test

1. Start **Explore Wildlands** or continue a saved character.
2. Move using the bottom-left joystick into another world tile; movement should be smooth, not tile-locked.
3. Exit to the main menu, reopen **Explore Wildlands**, and confirm the explorer resumes at the last entered tile rather than the origin.
4. Confirm rivers, trees and rocks still block movement and diagonal movement remains speed-normalized.
5. Confirm the separate **Isometric Test Room** remains a 5×5 grid demo; it is not the main world.
